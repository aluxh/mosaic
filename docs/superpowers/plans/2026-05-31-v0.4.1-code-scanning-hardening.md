# v0.4.1 Code Scanning Hardening Implementation Notes

**Status:** Shipped — 2026-05-31 as `v0.4.1`.

**Goal:** Address GitHub CodeQL findings raised after the v0.4 thumbnail
pipeline shipped, without changing guest-facing behavior.

**Shipped changes:**

- Upload route validates event ids and verifies resolved upload paths stay
  under the uploads root before filesystem writes.
- API registers `@fastify/rate-limit` globally before route registration.
- Contribute sheet no longer creates or renders local object URL previews,
  removing the CodeQL-flagged DOM flow.
- Route/component tests cover path safety, rate limiting, and HTML-looking
  error text rendering.

**Verification:**

- Local `api`: `npm test -- --run`, `npm run typecheck`
- Local `web`: `npm test -- --run`, `npm run typecheck`
- GitHub PR #9: CI and CodeQL green

**Note:** CodeQL did not model Fastify's global rate-limit plugin on the
photo upload route. The remaining modeled alert was dismissed as a false
positive after the standard plugin was installed and route-level `429`
regression coverage was added.
