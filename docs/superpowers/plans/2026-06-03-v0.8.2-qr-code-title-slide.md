# QR Code on Title Slide Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `GET /join` redirect endpoint that mints a fresh token, and render a scannable QR code in the title card slide pointing to it.

**Architecture:** A new `registerJoinRoute` function (in `api/src/routes/join.ts`) wires `/join` into the Fastify app — it mints a token on each request and redirects to `${BASE_URL}/#t=${token}` (or `/#t=${token}` if `BASE_URL` unset). `TitleCardSlide` computes `window.location.origin + '/join'` and renders a QR SVG via `react-qr-code`, replacing the existing `mosaic.live / {shortCode}` line at the bottom.

**Tech Stack:** Fastify 5, existing `mintToken` (`api/src/lib/token.ts`), `react-qr-code` (new npm dep), React, Vitest + Testing Library.

- [ ] **Step 3: Create `api/src/routes/join.ts`**

```ts
import type { FastifyInstance } from 'fastify';
import { mintToken } from '../lib/token.js';

export function registerJoinRoute(
  app: FastifyInstance,
  opts: { tokenSecret: string; eventId: string; ttlDays: number; baseUrl?: string },
): void {
  app.get('/join', async (_req, reply) => {
    const { token } = mintToken({
      secret: opts.tokenSecret,
      eid: opts.eventId,
      ttlDays: opts.ttlDays,
      baseUrl: opts.baseUrl,
    });
    const url = opts.baseUrl ? `${opts.baseUrl}/#t=${token}` : `/#t=${token}`;
    return reply.redirect(url);
  });
}
```
