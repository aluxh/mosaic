# v0.4 Thumbnail Pipeline Implementation Plan

**Status:** Shipped — 2026-05-31 as `v0.4.0`.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate downscaled `1024w` and `320w` variants for every photo at ingest (plus a one-time boot backfill for pre-v0.4 photos) and let each slide template load the smallest variant that still looks right.

**Architecture:** Convention-only storage. Variants live under `data/variants/<eventId>/` named `<base>-<width><ext>`, derived from the normalized (rotated, EXIF-stripped) buffer produced by `ingestImage`. No DB schema change and no migration: a boot backfill guarantees every photo row has variant files on disk, and variant URLs are computed from the filename. The API adds `url_1024`/`url_320` next to `url`; the web maps these to `url1024`/`url320` and each slide picks its variant.

**Tech Stack:** TypeScript, Node (`node:fs`/`node:path`), `sharp@0.33.5`, Fastify, better-sqlite3, Vitest, React, `@testing-library/react`.

**Repo conventions to mirror (verified):**
- API tests live in `api/test/*.test.ts` and import implementation from `../src/...`. They build a DB with `openDatabase(':memory:')` + `applySchemaFromString(db, SCHEMA)`, where `SCHEMA` is read from `api/migrations/*.sql`. There is **no** `api/src/**/*.test.ts`.
- Web tests live in `web/src/test/*` (vitest + jsdom, setup `src/test/setup.ts`). The web API client is `web/src/lib/api.ts`. There is **no** `SlideRenderer`; `web/src/components/Wall.tsx` switches on `slide.type` and renders the slide components. Duo/Triptych/Hero render images via the `KenBurns` component (which renders an `<img src=…>`); `PolaroidSlide` renders a plain `<img>`.

**Convention (applies throughout):** variant of `<base><ext>` is `<base>-1024<ext>` and `<base>-320<ext>`, same format as the source. Quality: 1024w → jpeg/webp q82 (jpeg uses mozjpeg), png compressionLevel 9; 320w → jpeg/webp q75, png compressionLevel 9. `withoutEnlargement: true` so a source narrower than the target is never upscaled.

export async function generateVariant(
  buf: Buffer,
  format: 'jpeg' | 'png' | 'webp',
  width: number,
): Promise<Buffer> {
  const pipeline = sharp(buf).resize({ width, withoutEnlargement: true });
  if (format === 'jpeg') {
    return pipeline.jpeg({ quality: width >= 1024 ? 82 : 75, mozjpeg: true }).toBuffer();
  }
  if (format === 'png') {
    return pipeline.png({ compressionLevel: 9 }).toBuffer();
  }
  return pipeline.webp({ quality: width >= 1024 ? 82 : 75 }).toBuffer();
}

export async function ensureVariants(
  variantsDir: string,
  filename: string,
  originalBuf: Buffer,
  format: 'jpeg' | 'png' | 'webp',
): Promise<void> {
  fs.mkdirSync(variantsDir, { recursive: true });
  for (const width of VARIANT_WIDTHS) {
    const target = path.join(variantsDir, variantFilename(filename, width));
    if (fs.existsSync(target)) continue;
    const out = await generateVariant(originalBuf, format, width);
    fs.writeFileSync(target, out);
  }
}
```

import fs from 'node:fs';
import path from 'node:path';
import type { DB } from '../db/index.js';
import { listPhotos } from '../db/queries.js';
import {
  seedsDirFor,
  uploadsDirFor,
  variantsDirFor,
  type StoragePaths,
} from './storage.js';
import { ensureVariants, variantFilename, VARIANT_WIDTHS } from './variants.js';

function formatFromExt(filename: string): 'jpeg' | 'png' | 'webp' | null {
  const ext = path.extname(filename).toLowerCase();
  if (ext === '.jpg' || ext === '.jpeg') return 'jpeg';
  if (ext === '.png') return 'png';
  if (ext === '.webp') return 'webp';
  return null;
}

export async function backfillVariants(db: DB, paths: StoragePaths, eventId: string): Promise<void> {
  const variantsDir = variantsDirFor(paths, eventId);
  for (const row of listPhotos(db, eventId)) {
    const allPresent = VARIANT_WIDTHS.every((w) =>
      fs.existsSync(path.join(variantsDir, variantFilename(row.filename, w))),
    );
    if (allPresent) continue;

    const format = formatFromExt(row.filename);
    if (!format) continue;

    const sourceDir = row.source === 'seed' ? seedsDirFor(paths, eventId) : uploadsDirFor(paths, eventId);
    const originalPath = path.join(sourceDir, row.filename);
    if (!fs.existsSync(originalPath)) continue;

    const originalBuf = fs.readFileSync(originalPath);
    await ensureVariants(variantsDir, row.filename, originalBuf, format);
  }
}
```
